# Administrator Guide

## Initial setup

1. Create company-scoped territories and keep each territory assigned to its operational company.
2. Create active salesperson assignments with valid effective dates.
3. Allocate customers to territories using the company-specific allocation records. Archive an old allocation before creating a replacement where required.
4. Add approved customer visit locations with validated coordinates and an appropriate radius.
5. Configure the company's GPS policy and exception behavior. A browser observation is client-reported evidence, not cryptographic proof of presence.
6. Review the supplied meeting outcomes and configure company-specific outcomes and validation requirements.
7. Give each user access only to the companies and Field Sales role needed for their work.

## Multi-company operation

Company-neutral contacts can have separate company-specific territory allocations and approved visit locations. Users must switch only among companies already authorized in their Odoo user settings. Do not use application role membership as a reason to broaden company access.

## GPS and privacy

Location is requested only for a user-initiated visit action. There is no continuous tracking. Explain location collection to staff, determine the applicable lawful basis and notices, and set an organizational retention policy. Do not treat an approved exception as a verified proximity result.
